# Java — Estudos e Práticas

Repositório dedicado aos estudos de **Java** durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

Aqui estão organizados os códigos, exercícios práticos e atividades desenvolvidos durante as aulas, acompanhando minha evolução no aprendizado da linguagem.

## Conteúdo

- Exercícios desenvolvidos durante as aulas.
- Exemplos práticos de programação.
- Aplicação dos conceitos apresentados em sala.
- Atividades e desafios propostos ao longo do curso.

## Tecnologias utilizadas

- Java
- IDE utilizada nas aulas

## Objetivo

Documentar minha jornada de aprendizado em Java, consolidar os fundamentos da programação e manter um histórico dos códigos desenvolvidos durante a graduação.
